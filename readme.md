# 信息系统监理师 刷题系统

📚 信息系统监理师考试刷题网站，支持练习题 + 案例题，错题本 + 收藏功能。

## 功能
- 📝 **练习题模式**：一道一道出题，支持选择题交互判断
- 📂 **案例题模式**：完整案例阅读
- ❌ **错题本**：自动收录错题，支持单独复习
- ⭐ **收藏**：标记重要题目
- 🔍 **搜索**：按关键词搜索题目
- 📅 **时间筛选**：按年份筛选，默认最新优先
- ⌨️ **键盘快捷键**：← 上一题 / →/空格 下一题
- 💾 **进度保存**：localStorage 本地存储

## 部署到 GitHub Pages
1. 推送代码到 GitHub 仓库
2. Settings → Pages → Source: Deploy from branch → main / root
3. 访问 `https://<username>.github.io/<repo>/`

## 本地预览
```bash
npx serve .
# 或
python -m http.server 8000
```
